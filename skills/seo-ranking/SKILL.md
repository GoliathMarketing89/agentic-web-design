# SEO Ranking

Converts *How To Get To The Top Of Google: The Plain English Guide To SEO* by
Tim Cameron-Kitchen, Dale Davies, Jess Percival, and Exposure Ninja into
operating instructions for an agent working with a user to improve a website's
ability to rank on Google's first pages. It is not a guarantee of position one.
The agent's job is to help the user give Google stronger reasons to rank the
site by improving relevance, authority, quality, usability, and promotion.

## Core Operating Principles

1. Treat SEO as persuasion, not control. The agent cannot force Google to rank a
   page. It can help the user build the evidence Google needs: relevant pages,
   useful content, clean structure, trust signals, strong links, and measurable
   user value.
2. Work from the business goal backward. Rankings matter because they create
   traffic, leads, sales, and money. Do not optimize for vanity keyword counts
   when the keyword does not bring useful buyers.
3. Prioritize low-hanging fruit first. The book's order matters: review the
   website, choose profitable keywords, analyze competitors, improve the site,
   then promote it.
4. Use one strong website unless there is a real business reason to split. For
   most local and service businesses, build location or service pages on the
   main domain instead of scattering effort across microsites.
5. Write for people first, but still deliberately optimize. Natural, useful,
   specific content should also use the customer's language, target keywords,
   clear headings, internal links, and compelling search snippets.
6. Build authority with real promotion. Good links come from websites that real
   people visit, trust, and find useful. Avoid junk directories, link farms, mass
   submissions, and links that exist only for SEO.
7. Measure outcomes and refocus. Track organic leads, sales, revenue, relevant
   keyword movement, Search Console data, and content/link progress. Use the
   data to decide the next sprint.

## Agent Intake

Before recommending work, ask the user for:

- Website URL.
- Business type, core services, products, and margins.
- Target locations or service areas.
- Best customers and common buyer questions.
- Existing CMS or platform.
- Access status for Google Search Console, analytics, Google Business Profile,
  website admin, and keyword tools.
- Current ranking goals and known competitors.
- Constraints: budget, timeline, developer access, content capacity, and whether
  they want DIY, outsourced, or agent-assisted execution.

If the user cannot provide tool access, continue with public-site and public-SERP
analysis, then mark every assumption clearly.

## Phase 1: Establish The Ranking Targets

### 1. Brainstorm Seed Keywords

Work with the user to list the plain-English names for the services, products,
categories, and problems the business solves. Include buyer-language variants,
not just internal company terminology.

For each seed keyword, capture:

- Product or service represented.
- Commercial intent: buyer, researcher, DIY, job seeker, entertainment, or unrelated.
- Location modifier if relevant.
- Likely landing page.
- Business value if the keyword ranks.

### 2. Pull Existing Search Data

If Search Console is available:

- Review queries generating impressions and clicks.
- Identify pages already appearing in search.
- Find keywords ranking below page one or low on page one.
- Flag pages with high impressions but weak click-through rate.
- Export query, page, clicks, impressions, CTR, and average position.

### 3. Use Keyword Tools Without Worshiping The Numbers

Use Semrush, equivalent tools, or user-provided exports to expand keyword ideas.
Treat volumes as estimates, not truth. A low-volume phrase can be valuable when
it exactly matches the buyer's intent.

For each keyword, score:

- Relevance to what the business sells.
- Commercial value.
- Ranking difficulty.
- Current site fit.
- Whether Google already shows pages like the user's page.

### 4. Check Competitor Keywords

Identify competitors ranking for the target terms. SEO competitors are the sites
ranking in Google, not always the user's business rivals.

For each competitor, document:

- Keywords they rank for.
- Pages that rank.
- Page type: homepage, service page, category page, blog, guide, directory
  listing, local pack, or featured snippet.
- Content depth and structure.
- Backlink strength and notable referring domains.
- Review volume and local signals if local intent appears.

### 5. Validate The SERP

Search each priority keyword in an unbiased browser profile. Record what Google
actually shows:

- Organic results.
- Local map pack.
- Featured snippets or answer boxes.
- Ads.
- Directories or review sites.
- Video results.
- Ecommerce/category/product results.
- Informational articles.

If the SERP is not showing pages like the user's proposed page, adjust the
target page or keyword. Search intent wins.

### 6. Map Keywords To Key Pages

Create a keyword map:

| Page | Topic | Primary Keyword | Secondary Keywords | Intent | Needed Action |
| --- | --- | --- | --- | --- | --- |
| Homepage | Main offer |  |  |  |  |
| Service page |  |  |  |  |  |
| Location page |  |  |  |  |  |
| Knowledge base article |  |  |  |  |  |
| Blog post |  |  |  |  |  |

Avoid targeting every keyword from the homepage. Build or improve the page that
best deserves to rank for each topic.

## Phase 2: Analyze Competition

For each priority keyword, inspect the current top results and answer:

- Which websites appear more than once?
- Are the top results large brands, local businesses, directories, marketplaces,
  or publishers?
- Are competitors using Google Ads for the keyword?
- Does a map pack appear?
- How many Google reviews do the visible local competitors have?
- What page type is Google rewarding?
- How long, useful, and specific is the competing content?
- What headings, FAQs, images, and calls to action do they use?
- How is their site structured?
- How many backlinks and referring domains appear to support them?

Turn the competitor analysis into a gap list:

- Content gaps: missing pages, thin copy, missing FAQs, weak knowledge base, no
  blog support.
- Technical gaps: mobile, speed, broken links, crawl/indexation, duplicate content.
- Authority gaps: fewer relevant links, weaker directories, no PR, no influencer
  or data outreach.
- Local gaps: incomplete Google Business Profile, weak review count, inconsistent
  citations.
- Conversion gaps: unclear next step, poor trust signals, missing proof.

## Phase 3: Fix Website Foundations

### Website Platform

Prefer a CMS or platform that lets the user edit pages, publish content, control
metadata, and maintain the site without rebuilding everything. WordPress is
treated in the book as a strong default for many content-led sites; Shopify can
be appropriate for ecommerce.

### Domains And URLs

Follow these rules:

- Choose a domain that is clear, memorable, and aligned with the business.
- Do not rely on exact-match domains as a ranking trick.
- Avoid buying many domains and pointing them at the main site as an SEO strategy.
- Use short, descriptive URLs.
- Include useful words in page URLs when natural.
- Avoid meaningless URL strings.
- Use folders to reflect site structure, such as `/services/roof-repair/` or
  `/locations/calgary/`.
- Keep one canonical page for each topic.

### Site Structure

Create a simple hierarchy:

- Homepage.
- Main service or product categories.
- Specific service, product, or subcategory pages.
- Location pages where local targeting matters.
- Knowledge base or FAQ hub.
- Blog resources.
- About, contact, proof, and policy pages.

Rules:

- Give each major service its own page.
- Give each important location its own useful location page.
- Keep navigation clear and not overstuffed.
- Internally link from broad pages to specific pages.
- Internally link from educational content to commercial pages.
- Avoid hiding important pages deep in the site.

### Sitemaps

Make sure the site has an XML sitemap and submit it in Google Search Console.
HTML sitemaps are only useful when the site's navigation is otherwise difficult
for humans.

## Phase 4: Build Pages That Deserve To Rank

### Page Content Standard

Every key page should be:

- Original.
- Well researched.
- Supported by useful references or proof where appropriate.
- Insightful beyond obvious statements.
- Comprehensive for the search intent.
- Expert-led, authoritative, and trustworthy.
- Clear, readable, and free from sloppy spelling or grammar.
- Enhanced with appropriate images, video, tables, examples, or diagrams.
- Accessible on mobile and desktop.
- Useful enough that a visitor would bookmark, share, or act on it.

### Service Or Product Page Writing Formula

For every important page, the agent should help the user draft or improve content
using this structure:

1. State exactly what is being sold or offered.
2. Explain who it is for.
3. Explain how the service, product, or process works.
4. Answer the questions customers ask before buying.
5. Explain why customers choose this business over alternatives.
6. Handle objections and risks.
7. Add trust signals: proof, reviews, examples, credentials, guarantees, case
   studies, or photos.
8. Include the target location if local relevance matters.
9. Use a clear next step: call, form, booking, quote, product purchase, or
   consultation.

### Keyword Usage

Use the customer's words. Place the primary keyword or close variant in:

- Page title.
- H1.
- Opening copy when natural.
- At least one H2 or supporting section when natural.
- URL when appropriate.
- Meta description for relevance and click appeal.
- Image alt text only when it accurately describes the image.
- Internal anchor text where relevant.

Avoid keyword stuffing. If the copy sounds awkward, rewrite it for humans.

### Headings

Use one H1 for the main page topic. Use H2s for major sections and H3s for
subsections. Headings should help users scan and help Google understand the
page's structure.

### Duplicate Content

Do not copy manufacturer descriptions, competitor copy, or the same service text
across many location pages with only the city swapped. For ecommerce, rewrite
important product and category descriptions so the page has unique value.

### Ecommerce Content

For large stores:

- Prioritize unique copy for the products and categories that matter commercially.
- Add category descriptions where useful.
- Use product-specific benefits, specs, FAQs, delivery information, comparisons,
  and buyer guidance.
- Link from guides and knowledge base articles to relevant categories and products.

## Phase 5: Create Knowledge Bases, FAQs, And Blog Assets

### Knowledge Base Strategy

Use a knowledge base or FAQ hub to capture informational searches and demonstrate
expertise. Start with one topic cluster if resources are limited.

Workflow:

1. Choose a topic tied to a profitable product or service.
2. Use keyword research to collect informational searches.
3. Group searches into categories, overview pages, and supporting pages.
4. Build an overview guide that links to deeper articles.
5. Build detailed subtopic pages.
6. Link every educational page to relevant commercial pages.
7. Add clear calls to action inside the helpful content.

Example structure:

- Main guide page.
- Subtopic overview pages.
- Detailed question pages.
- Product, service, or location pages linked from the educational content.

### Blog Strategy

Use blog posts to answer questions buyers ask before they buy.

Workflow:

1. Brainstorm questions from sales calls, emails, objections, and customer
   conversations.
2. Use autocomplete, People Also Ask, forums, competitor blogs, and keyword tools
   to expand.
3. Check search volume and SERP intent, but do not discard a commercially perfect
   question just because the tool estimates low volume.
4. Plan the post with headings before drafting.
5. Make the post detailed, useful, and specific enough to show the business's
   expertise.
6. Use a compelling but accurate title.
7. Optimize headings, internal links, metadata, images, and calls to action.
8. Publish related posts that support a broader guide, then link them together.

Blog posts should not be generic filler. They should bring qualified people into
the site and move them toward a commercial page or next step.

## Phase 6: Optimize Search Snippets And Behind-The-Scenes Elements

### Page Titles

Page titles are one of the fastest on-page wins. For each key page:

- Put the main keyword near the front where natural.
- Include location when local intent matters.
- Add the brand when useful.
- Make the title specific and compelling.
- Avoid vague slogans.
- Avoid repeating the same title across pages.

### Meta Descriptions

Meta descriptions are mainly for click-through, not direct ranking. Write them
to attract the right searcher.

Use:

- Specific offer or benefit.
- Relevant keyword language.
- Location if applicable.
- Commercial proof or differentiator.
- Free consultation, delivery, quote, or next step where relevant.
- Around 150 to 155 characters as a practical target.

Avoid:

- Keyword stuffing.
- Generic claims like "best quality, best service" without proof.
- Duplicate descriptions across pages.

### Images

For every important image:

- Use a descriptive filename before upload.
- Compress the image.
- Add alt text that describes the image accurately.
- Avoid spammy alt text that exists only to repeat keywords.

### Schema

Add structured data where it fits the business:

- Local business.
- Product.
- Event.
- Restaurant.
- FAQ where appropriate and compliant.
- Organization.
- Contact details.

Validate schema with a structured data testing tool. Do not promise that Google
will display rich results; the goal is to give Google eligible data.

## Phase 7: Technical Quality, Mobile, And Speed

### Mobile

Prefer responsive design over a separate mobile site. The mobile version should
include the same important content, links, and functionality as desktop.

Check:

- Text readability.
- Tap targets.
- Navigation.
- Forms and checkout.
- Content parity.
- Page speed.
- Intrusive elements.

### Speed

Use PageSpeed Insights and another speed tool to diagnose. Treat perfect scores
as less important than meaningful improvements for users, especially on mobile.

Common fixes:

- Compress and resize images.
- Use browser caching.
- Reduce unnecessary JavaScript and CSS.
- Improve hosting if the server is slow.
- Use a CDN such as Cloudflare where appropriate.
- Remove heavy plugins or third-party scripts that do not justify their cost.

The book emphasizes that speed affects both rankings and user behavior; even
small delays can reduce engagement.

### Search Console

Set up Google Search Console and use it continuously:

- Submit XML sitemap.
- Monitor clicks, impressions, CTR, and average position.
- Find pages appearing in search but not earning clicks.
- Find queries that deserve new or improved pages.
- Check indexed pages.
- Review manual actions.
- Review security issues.
- Review links.

If manual actions exist, solve the cause before continuing normal SEO work.

## Phase 8: Local SEO And Google Business Profile

For local businesses:

1. Claim and complete Google Business Profile.
2. Keep name, address, phone, website, hours, and categories accurate.
3. Add photos, services, products, and business details.
4. Build consistent citations in quality directories.
5. Ask for reviews systematically.
6. Automate review requests where possible.
7. Never buy fake reviews.
8. Monitor negative or suspicious results around the brand name.

The agent should help the user build a review request process that happens after
successful service delivery, not rely on occasional manual asking.

## Phase 9: Build Authority With Links And Promotion

### Link Quality Standard

A good link usually comes from a site that:

- Real people visit.
- Is relevant to the user's topic, industry, location, or audience.
- Has editorial standards.
- Would still be worth appearing on if Google did not exist.
- Can send referral traffic, trust, or brand exposure.

A bad link often comes from:

- Sites made only for SEO.
- Auto-approved directories.
- Irrelevant link farms.
- Paid link schemes.
- Spammy sites with no useful audience.
- Pages where the main call to action is "submit link."

Third-party metrics such as Domain Authority, Page Authority, Trust Flow, and
Citation Flow can help prioritize outreach, but they are not Google metrics. Use
them as shortcuts, not as final truth.

### Phase 1 Links: Quick Foundations

Start with easy, legitimate links:

- Relevant business directories.
- Market-specific directories.
- Local citations.
- Supplier, partner, association, or chamber listings.
- YouTube channel and video descriptions with full clickable URLs.
- Other video platforms where the business already has content.
- Social and profile links where useful.

Do not spend excessive time on directories. They are a starting point, not the
main campaign. For the full local link-building playbook, see the
`local-link-building` skill in this repo.

### Digital PR

Use digital PR to earn coverage from publications the audience already reads.

Workflow:

1. Identify publications, trade sites, local media, and blogs the audience trusts.
2. Look for topics editors need help covering.
3. Create a pitch that gives the journalist or editor a useful story, expert
   comment, data point, or angle.
4. Make the connection between the story and the business natural.
5. Follow up politely.
6. Track placements, links, mentions, referral traffic, and follow-on opportunities.

### Data Outreach And Surveys

Use surveys or original data to create newsworthy stories.

Workflow:

1. Draft the headline you would want a publication to run.
2. Check whether the headline connects to a current trend and the user's expertise.
3. Design a question that could produce the story.
4. Choose relevant demographics or segments.
5. Test the survey internally before paying for responses.
6. Collect results.
7. Write an article explaining the findings.
8. Turn the data into visual assets if possible.
9. Pitch journalists and publish a press release where useful.
10. Link the story back to a relevant page on the site.

### Blogger And Influencer Outreach

Use this when the product or service is naturally interesting to bloggers,
reviewers, creators, or communities.

Potential offers:

- Free product.
- Service trial.
- Multiple products for review or comparison.
- Giveaway item for the audience.
- Exclusive discount code.
- Affiliate arrangement.
- Event invite.
- Community or ambassador program.
- Content ideas that make the creator's job easier.

The agent should not recommend influencer outreach for businesses where creators
are unlikely to care about the offer.

### Inbound PR Requests

Monitor journalist request services and social channels where journalists ask
for experts. Respond quickly with concise, useful, quotable expertise. Track
successful placements and build relationships with journalists who cover the
user's field.

## Phase 10: Build The SEO Strategy

The book's priority order should become the campaign plan:

1. Website review.
2. Keyword targeting.
3. Competitor analysis.
4. Website optimization.
5. Phase 1 links.
6. Phase 2 links and content marketing.
7. Measure progress and refocus.

### Website Review Checklist

Check:

- Is the site mobile friendly?
- Is it fast enough on mobile?
- Does it look trustworthy?
- Is the design credible for the market?
- Does it have enough useful content?
- Does it have a blog, knowledge base, or FAQ opportunity?
- Are the main services/products represented by dedicated pages?
- Are locations represented by useful pages where needed?
- Are there broken links or obvious technical errors?
- Are titles and meta descriptions unique and compelling?
- Are calls to action obvious?
- Does the site look like it deserves to rank at the top?

### Prioritization Matrix

For every recommendation, score:

| Task | Impact | Effort | Confidence | Dependency | Owner | Due Date |
| --- | --- | --- | --- | --- | --- | --- |
|  | High/Med/Low | High/Med/Low | High/Med/Low |  |  |  |

Start with high-impact, low-effort items that improve key pages or fix blockers.
Then move into larger content and promotion campaigns.

## Phase 11: Measure Progress

The book's hierarchy of measurement is clear: money is the end goal.

Track:

- Organic revenue.
- Organic leads.
- Organic conversion rate.
- Organic traffic.
- Rankings for relevant target keywords.
- Number of relevant keywords ranking.
- Search Console clicks, impressions, CTR, and average position.
- Key page performance.
- New referring domains and link quality.
- Local pack visibility.
- Google Business Profile actions and reviews.
- Content published.
- Outreach sent, replies, placements, and links earned.

Report progress in business terms first, then SEO terms.

### Monthly Review Loop

Each month:

1. Compare organic leads, sales, and revenue to the previous period.
2. Review Search Console query and page changes.
3. Identify pages with rising impressions but low CTR.
4. Identify pages ranking positions 4 to 20 that can be improved.
5. Check new backlinks and lost backlinks.
6. Review technical warnings.
7. Review content published and indexed.
8. Review outreach progress.
9. Decide the next sprint based on the best opportunity.

## Agent Content Drafting Prompt

When drafting for the user, follow this internal prompt:

```text
Draft this page to be useful enough to deserve a top Google ranking for the
target query. Use the customer's language. Explain the offer clearly, answer
real buyer questions, handle objections, include proof, structure with one H1
and useful H2/H3 sections, and include a clear next step. Do not stuff keywords.
Do not copy competitor or manufacturer text. Make the page more useful than the
current ranking pages for the same intent.
```

## Agent Execution Rules

- Do not promise position one.
- Do not hide uncertainty in keyword volume or ranking difficulty.
- Do not create generic content just to publish something.
- Do not recommend multiple websites unless there is a strong business case.
- Do not recommend fake reviews or low-quality paid links.
- Do not treat third-party link metrics as Google truth.
- Do not optimize pages without mapping them to search intent.
- Do not write location pages that only swap city names.
- Do not measure success only by rankings.
- Always tie SEO work back to qualified traffic, leads, sales, or revenue.
