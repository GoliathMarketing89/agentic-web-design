Install

All three skills, via skills.sh:

# all skills
npx skills add goliathmarketing89/agentic-web-design

# individual skills
npx skills add goliathmarketing89/agentic-web-design/agentic-web-design
npx skills add goliathmarketing89/agentic-web-design/seo-ranking
npx skills add goliathmarketing89/agentic-web-design/local-link-building

Each skill is self-contained — a single SKILL.md with everything the agent needs. Works with Claude Code, Codex, Cursor, and other skills.sh-compatible agents.

The rule that governs everything

Websites need to convert, not impress. Cinematic styling is garnish; conversion structure is the meal. Every skill here is built around that — design for conversion, rank for traffic, build authority with links that would make sense even if search didn't exist.
